## Design observations

The homepage is built with Elementor and a PixFort header. Visible sections cover an AI-search demonstration, marketing and software service pillars, brand and video services, industry links, operating claims, client quotes, an FAQ accordion, offices, and a consultation prompt. A project counter is present, but the static HTML shows "0 +" because the finished number is applied in the browser. Separate copy on the same page says the company shipped over 5,000 projects.

## Navigation architecture

The desktop header contains six top-level items: Home, Marketing services, Software services, About, Contact, and Get AI Visibility Audit. Marketing services and Software services are dropdowns. Their children are listed in `research/json/navigation.json`. The footer repeats service links and adds proposal, policy, social, phone, Calendly, and a public scam-warning link. The public menu API returned 401, so this structure was read from homepage HTML rather than from an authenticated menu route. Service URLs also show hierarchy through `/digital-marketing-services/` and `/software-development-services/`.

## Content architecture

Content is organized as WordPress pages for services and company information, a portfolio post type for case studies, and a large blog. All in One SEO Pro publishes the XML sitemaps and `llms.txt`. Category, tag, and portfolio-type archives group the longer-form content.

## Interactive features

- Homepage FAQ accordion (PixFort collapse markup).
- A homepage prompt asks for a brand name in an AI-search demonstration. No form action was present in the fetched homepage.
- Contact and proposal paths are linked. Scheduling is linked to Calendly.
- Formidable Forms and Jetpack form styles are loaded. This pass did not submit any form.

## Technical observations

Pages are server-rendered HTML with client-side assets for Elementor, PixFort, WooCommerce, Jetpack, and Google tag loading. The WordPress REST API is public for published content and returns 401 for menus. See technology-analysis.md for evidence and confidence.
